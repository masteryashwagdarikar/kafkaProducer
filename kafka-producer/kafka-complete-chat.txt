steps to install apache kafka on my local machine

Here is a step-by-step guide to installing and running Apache Kafka locally on your machine.

Since Kafka relies on Java, we will start by checking your environment and then use the modern KRaft mode (which runs Kafka without needing Apache ZooKeeper).

Step 1: Install Java (Prerequisite)
Kafka requires Java to run.

Open your terminal or command prompt and check if Java is installed:

Bash
java -version
If Java isn't installed (or if it's older than Java 11), download and install Java (JDK 17 or newer) from Oracle or Eclipse Temurin (OpenJDK). Make sure your JAVA_HOME environment variable is set.

Step 2: Download Apache Kafka
Go to the official Apache Kafka Downloads page.

Download the latest binary release (choose a .tgz file under Scala, for example, kafka_2.13-3.x.x.tgz).

Extract the downloaded archive to a folder on your local machine (e.g., C:\kafka on Windows or /usr/local/kafka on macOS/Linux).

Step 3: Start Kafka using KRaft (No ZooKeeper required)
Modern versions of Kafka use KRaft (Kafka Raft Metadata Mode), which simplifies startup by removing the need for ZooKeeper.

For macOS / Linux:
Open your terminal and navigate to your Kafka installation directory:

Bash
cd /path/to/kafka
Generate a unique cluster ID:

Bash
KAFKA_CLUSTER_ID="$(bin/kafka-storage.sh random-uuid)"
Format the log directory with the cluster ID:

Bash
bin/kafka-storage.sh format -t $KAFKA_CLUSTER_ID -c config/kraft/server.properties
Start the Kafka server:

Bash
bin/kafka-server-start.sh config/kraft/server.properties
For Windows:
Open Command Prompt or PowerShell and navigate to your Kafka folder (e.g., cd C:\kafka).

Generate a cluster ID:

DOS
bin\windows\kafka-storage.bat random-uuid
(Copy the generated UUID string)

Format the log directory using your generated UUID:

DOS
bin\windows\kafka-storage.bat format -t <YOUR_CLUSTER_ID> -c config\kraft\server.properties
Start the Kafka server:

DOS
bin\windows\kafka-server-start.bat config\kraft\server.properties
Note: Keep this terminal window open. If you close it, your Kafka broker will stop running.

Step 4: Test Your Kafka Setup
Open a new terminal or command prompt window in your Kafka directory to test producing and consuming messages.

Create a Kafka Topic named quickstart-events:

Mac/Linux: bin/kafka-topics.sh --create --topic quickstart-events --bootstrap-server localhost:9092

Windows: bin\windows\kafka-topics.bat --create --topic quickstart-events --bootstrap-server localhost:9092

Start a Producer to send messages:

Mac/Linux: bin/kafka-console-producer.sh --topic quickstart-events --bootstrap-server localhost:9092

Windows: bin\windows\kafka-console-producer.bat --topic quickstart-events --bootstrap-server localhost:9092

Type a few lines of text (e.g., Hello Kafka, My first message) and press Enter after each.

Start a Consumer (in yet another new terminal) to read the messages:

Mac/Linux: bin/kafka-console-consumer.sh --topic quickstart-events --from-beginning --bootstrap-server localhost:9092

Windows: bin\windows\kafka-console-consumer.bat --topic quickstart-events --from-beginning --bootstrap-server localhost:9092

You should see the messages you typed in the producer window appear here instantly!

Next Steps
To stop Kafka, press Ctrl + C in the terminal running the server.

If you want a graphical user interface (GUI) later to manage topics and messages easily, you can look into lightweight tools like Offset Explorer or Kafka UI (by Provectus).

import org.springframework.kafka.core.KafkaTemplate;
import org.springframework.stereotype.Service;

@Service
public class KafkaProducerService {

    private static final String TOPIC = "quickstart-events";

    @Autowired
    private KafkaTemplate<String, String> kafkaTemplate;

    public void sendMessage(String message) {
        System.out.println(f"Sending message to Kafka: " + message);
        kafkaTemplate.send(TOPIC, message);
    }
